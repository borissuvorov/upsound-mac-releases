# UpSound для Mac

Приложение UpSound CRM для Mac. Здесь лежат только готовые сборки — исходного кода нет.

## Как установить

Нужен Мак на процессоре Apple (M1 и новее) с macOS 14 или новее.

1. Нажмите ⌘ + Пробел, наберите «Терминал» и нажмите Enter.
2. Скопируйте строку ниже, вставьте её в Терминал (⌘ + V) и нажмите Enter:

```
curl -fsSL https://github.com/borissuvorov/upsound-mac-releases/releases/latest/download/install.sh | bash
```

3. Через полминуты UpSound откроется сам. Войдите в CRM — так же, как на сайте.

Терминал после этого можно закрыть.

## Агент в приложении

Справа в UpSound — панель агента (⌘J). Claude Code, Codex или Cursor отвечают по открытому экрану и предлагают правки задач и страниц базы знаний — вы принимаете их кнопкой. Агент работает по вашей подписке, ключи от CRM не нужны.

Подключается один раз:

1. Откройте панель агента: ⌘J. Пока агента нет, в ней карточка «Подключите агента».
2. Выберите агента. Нужна подписка: Claude Pro или Max — для Claude, ChatGPT Plus, Pro или Business — для Codex, Cursor — для Cursor.
3. Нажмите «Открыть Терминал». У строки «Установите в Терминале» нажмите «Скопировать», вставьте её в Терминал (⌘ + V) и нажмите Enter.
4. Так же скопируйте строку «Войдите один раз» и вставьте в Терминал. Откроется браузер — войдите аккаунтом с подпиской.
5. Вернитесь в UpSound. Если карточка не исчезла сама, нажмите «Проверить снова». Перезапускать приложение не нужно.

Другого агента подключить — в поле ввода нажмите на имя агента и выберите «подключить…» рядом с нужным.

## Обновления

UpSound обновляется сам. Когда выходит новая версия, внизу слева загорается «Вышла сборка …». Нажмите на неё — приложение перезапустится в новую версию за пару секунд.

## Если что-то пошло не так

- «Нет прав ставить программы в папку „Программы“» — попросите администратора этого Мака запустить команду.
- «Не получилось связаться с GitHub» — проверьте интернет и запустите команду ещё раз.
- Переустановить — та же команда.
- Агент пишет, что не вошёл в аккаунт, — нажмите на имя агента в поле ввода, выберите «не вошёл · как войти» и выполните строку «Войдите один раз».
