# UpSound для Mac

Приложение UpSound CRM для Mac. Здесь лежат только готовые сборки — исходного кода нет.

## Как установить

Нужен Мак на процессоре Apple (M1 и новее) с macOS 14 или новее.

1. Нажмите ⌘ + Пробел, наберите «Терминал» и нажмите Enter.
2. Скопируйте строку ниже, вставьте её в Терминал (⌘ + V) и нажмите Enter:

```
curl -fsSL https://github.com/borissuvorov/upsound-mac-releases/releases/latest/download/install.sh | bash
```

3. Через полминуты UpSound откроется сам. Войдите в CRM — так же, как на сайте.

Терминал после этого можно закрыть.

## Обновления

UpSound обновляется сам. Когда выходит новая версия, внизу слева загорается «Вышла сборка …». Нажмите на неё — приложение перезапустится в новую версию за пару секунд.

## Если что-то пошло не так

- «Нет прав ставить программы в папку „Программы“» — попросите администратора этого Мака запустить команду.
- «Не получилось связаться с GitHub» — проверьте интернет и запустите команду ещё раз.
- Переустановить — та же команда.
